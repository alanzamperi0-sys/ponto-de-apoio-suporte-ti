# Ponto de Apoio — Suporte de TI

## Sobre o projeto

O Ponto de Apoio é um sistema desenvolvido em Python com Streamlit para registrar e acompanhar chamados de suporte de Tecnologia da Informação (TI).

O projeto foi desenvolvido como parte do Projeto Integrador Transdisciplinar II (PIT II).

## Funcionalidades

- Cadastro de chamados de suporte.
- Visualização dos chamados registrados.
- Consulta aos detalhes de cada chamado.
- Atualização do status dos chamados.
- Armazenamento dos dados em banco de dados SQLite.
- Interface com recursos visuais personalizados.

## Tecnologias utilizadas

- Python
- Streamlit
- SQLite
- HTML
- CSS
- JavaScript

## Arquivos do projeto

- `app.py`: aplicação principal em Python.
- `index.html`: estrutura HTML complementar.
- `style.css`: estilos visuais da interface.
- `script.js`: funcionalidades complementares em JavaScript.

## Como executar o projeto

1. Instale o Python em seu computador.
2. Abra o terminal na pasta do projeto.
3. Instale o Streamlit com o comando:

   `python -m pip install streamlit`

4. Execute a aplicação com o comando:

   `python -m streamlit run app.py`

5. Abra no navegador o endereço local informado pelo Streamlit, normalmente `http://localhost:8501`.

## Banco de dados

O sistema utiliza SQLite para armazenar os chamados. O banco de dados é utilizado localmente pela aplicação.

## Objetivo acadêmico

O objetivo do projeto é desenvolver uma solução para auxiliar no registro e acompanhamento de solicitações de suporte de TI, aplicando conhecimentos de programação, interface e banco de dados.
